# Сквиш Кликер

HTML5-кликер для Яндекс Игр: мни модные сквиши, копи монетки-пузырики, покупай улучшения и собирай коллекцию.

## Что есть в игре

- **72 сквиша в трёх сериях** (спрайты в `assets/squishes/`): 24 дамплинга, 28 шейков и 20 капибар. Есть четыре редкости: обычные (+10% к доходу), редкие (+30%), эпические (+75%) и легендарные (+200%: Кристалл, Галактика, Золото). Сначала открываются обычные сквиши по очереди из каждой серии, потом редкие, эпические и легендарные. Цены растут.
- Сквиш сплющивается и пружинит при нажатии. При нажатии летят брызги цвета сквиша и цифры, работает мультитач.
- **Улучшения:** сила тапа, котики-помощники и фабрики (доход в секунду), супер-тап x5.
- **Звёздочка-бонус** появляется время от времени, её нужно успеть поймать.
- **x2 дохода на 60 секунд** за просмотр рекламы.
- **Доход, пока игрока нет** (максимум за 2 часа).
- Сохранение в браузере и в облаке Яндекса.
- Русский и английский язык, вёрстка под телефон и компьютер.
- Пробел или Enter на компьютере тоже мнут сквиш.

## Как запустить локально

Нужен любой локальный сервер (иначе браузер не даст загрузить звуки):

```bash
npx http-server -p 8080
# или
python3 -m http.server 8080
```

Затем открой http://localhost:8080. Без Яндекса реклама не показывается, а награда x2 выдаётся сразу. Это нормально.

## Как загрузить на Яндекс Игры

1. Заархивируй **содержимое** папки (чтобы `index.html` лежал в корне архива, без папки сверху):
   ```bash
   zip -r squish-clicker.zip index.html style.css js sounds assets
   ```
2. В [консоли разработчика Яндекс Игр](https://games.yandex.ru/console/) создай игру и загрузи архив.
3. SDK подключается строкой `<script src="/sdk.js"></script>` в `index.html`, этот файл отдаёт сама платформа.

Что уже сделано под требования Яндекса: `LoadingAPI.ready()`, разметка `GameplayAPI start/stop`, звук выключается во время рекламы и при сворачивании вкладки, нет контекстного меню и выделения текста, нет внешних ресурсов (CDN, шрифтов).

## Где что менять

| Что | Где |
|---|---|
| Звуки | папка `sounds/` (см. `sounds/README.md`), пути и громкость в `js/audio.js`, генератор `tools/make_sounds.py` |
| Спрайты сквишей | `assets/squishes/<серия>/`, превью 160px — в `thumbs/` рядом |
| Сквиши: редкость, цены, бонусы, порядок | `js/squishes.js` |
| Названия вкусов, серий и тексты | `js/i18n.js` |
| Улучшения и баланс | начало `js/game.js` |
| Цвета и вёрстка | `style.css` |

## Звуки

Все звуки в `sounds/` (три «чвяка», супер-тап, покупка, новый сквиш, звёздочка, клик и фоновая музыка на 40 секунд) синтезированы скриптом `tools/make_sounds.py`. Чужих сэмплов там нет, поэтому с лицензией проблем не будет. Пересобрать звуки:

```bash
pip install numpy scipy
python3 tools/make_sounds.py   # нужен ffmpeg
```

## Где искать другие звуки

Бесплатные библиотеки (по лицензии всегда проверяй, нужно ли указывать автора):

- **[Pixabay Sound Effects](https://pixabay.com/sound-effects/)** — бесплатно, можно без указания автора. Ищи `squish`, `slime`, `squeeze`, `pop`.
- **[Freesound](https://freesound.org/)** — самая большая база. Включай фильтр лицензии **CC0**, тогда автора указывать не нужно.
- **[Mixkit](https://mixkit.co/free-sound-effects/)** — короткие качественные эффекты (pop, bubble, cartoon).
- **[Kenney](https://kenney.nl/assets?q=audio)** — паки звуков интерфейса и мультяшных эффектов, лицензия CC0. Подходит для `buy`, `click`, `unlock`.
- **[ZapSplat](https://www.zapsplat.com/)** — много мультяшных и «желейных» звуков, бесплатно с указанием автора.
- **[OpenGameArt](https://opengameart.org/art-search-advanced?field_art_type_tid%5B%5D=13)** — звуки специально для игр.
- **[Sonniss GDC Bundle](https://sonniss.com/gameaudiogdc)** — огромные бесплатные архивы профессиональных звуков, можно использовать в коммерческих играх.
- **[sfxr.me](https://sfxr.me/)** / **[ChipTone](https://sfbgames.itch.io/chiptone)** — генераторы звуков прямо в браузере: «пиу», «дзынь», «поп».
- Музыка: **[Pixabay Music](https://pixabay.com/music/)** (ищи `cute`, `kawaii`, `happy`) и **[Incompetech](https://incompetech.com/music/royalty-free/)** (с указанием автора).

Слова для поиска: `squish`, `squishy`, `slime`, `squeeze`, `jelly`, `rubber squeak`, `bubble pop`, `cartoon pop`, `boing`, `coin`, `sparkle`, `level up`.

Совет: самый «настоящий» звук получится, если записать на телефон, как мнёшь настоящий сквиш или слайм, и обрезать запись в [Audacity](https://www.audacityteam.org/).

Не бери ASMR-звуки с YouTube и TikTok: у них нет лицензии, и модерация Яндекса может отклонить игру. Сохраняй ссылки на источники и лицензии звуков в отдельный файл.
