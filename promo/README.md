# Промо-материалы (в архив игры не попадают)

Загружаются в консоль разработчика отдельно. Тексты для всех полей — в `STORE.md`.

| Файл                              | Размер    | Что это |
|-----------------------------------|-----------|---------|
| `icon.png`                        | 512×512   | Иконка игры |
| `cover-<язык>.png`                | 800×470   | Обложка в каталоге с названием на нужном языке |
| `screen-desktop-<язык>-*.png`     | 1920×1080 | Скриншоты с компьютера: игра, коллекция, новый сквиш |
| `screen-mobile-<язык>-*.png`      | 1080×1920 | Скриншоты с телефона: то же самое |
| `video-<язык>.mp4`                | 1920×1080 | Видео геймплея ~35 с (H.264, без звука) |

Языки: `ru`, `en`, `tr`.

Пересобрать всё (нужны playwright и ffmpeg):

```bash
npm i playwright && npx playwright install chromium
node tools/promo.mjs                  # иконка, обложки, скриншоты, видео
node tools/promo.mjs art shots        # без видео
node tools/promo.mjs video --lang=ru  # только одно видео
```

Сцены (какие сквиши открыты, сколько монет) задаются в начале `tools/promo.mjs`.
Шрифт обложек — Nunito (лицензия SIL OFL, `tools/promo/fonts/OFL.txt`).
