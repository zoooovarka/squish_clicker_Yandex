# Звуки

Сейчас здесь лежат звуки, сгенерированные скриптом `tools/make_sounds.py` (свои, без чужих сэмплов).
Чтобы заменить любой из них, положи свой файл с тем же именем.
Если меняешь музыку, поставь `MUSIC_LOOP_SECONDS = null` в `js/audio.js`.

Положи сюда файлы с такими именами (формат `.mp3`; `.ogg`/`.wav` тоже можно — тогда поправь пути в `js/audio.js`):

| Файл | Когда играет |
|---|---|
| `dumpling1–3.mp3` | нажатие на дамплинг (каждый раз случайный из трёх) |
| `shake1–3.mp3` | нажатие на шейк |
| `capybara1–3.mp3` | нажатие на капибару (в третьем — «пуи!») |
| `crit.mp3` | супер-тап (x5): колокольчики поверх «чвяка» |
| `buy.mp3` | покупка улучшения |
| `unlock.mp3` | открыт новый сквиш |
| `bonus.mp3` | поймана звёздочка / включён x2 |
| `click.mp3` | выбор сквиша, не хватает монет |
| `music.mp3` | фоновая музыка по кругу (необязательно) |

Каких-то файлов нет — не страшно: вместо них играет встроенный синтезированный звук.

Звуки серий настраиваются в `SERIES_FILES`, отдельный звук конкретному сквишу — в `SQUISH_FILES` (`js/audio.js`).
Громкость — `SFX_VOLUME` и `MUSIC_VOLUME` там же.

Советы:
- Делай звуки короткими (0.1–0.4 с) и обрезай тишину в начале, иначе будет «задержка».
- Битрейт 96–128 kbps достаточно, архив для Яндекс Игр будет лёгким.
- Высота звука нажатия немного случайно меняется, поэтому даже один файл не надоедает.
